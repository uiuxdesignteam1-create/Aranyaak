# Aranyaak Luxury Resort website

Static website for **Aranyaak Luxury Resort**, Doluchora, Lawachara Road, Sreemangal, Moulvibazar 3210, Bangladesh.

- `index.html`: the whole site (HTML, CSS and JavaScript in one file), English and Bangla
- `img/`: photos (cottages, offers, dining, events, stories, 360° panoramas, menu background)
- `hero.mp4`, `hero2.mp4` (+ `-m` mobile versions): hero videos
- `band.mp4`: footer band video · `video-tour.mp4`: sample video tour

Open `index.html` in a browser, or serve the folder with any static host (GitHub Pages, Netlify).

> Several photos and videos are stock placeholders and must be replaced with the resort's own photography before launch. Online payment (SSLCOMMERZ) and booking storage are not connected yet.
